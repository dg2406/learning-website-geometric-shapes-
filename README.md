# 📐 Geometric Shapes Learning Website

A React-based interactive learning platform designed to help students understand geometric shapes, formulas, and concepts through visual learning, quizzes, and user progress tracking.

## 🚀 Features

### 🔹 Shape Learning
- Learn different geometric shapes:
  - Circle
  - Square
  - Triangle
- Interactive shape visualization
- Formula explanations for area and perimeter

### 🔹 Quiz System
- Geometry-based MCQ quiz
- Countdown timer
- Instant score calculation
- Quiz attempt history stored locally
- Pass/fail result display

### 🔹 User Authentication
- User registration
- Login system
- Logout functionality
- Protected dashboard access
- User data management using local storage

### 🔹 Dashboard
- Personalized user dashboard
- Displays:
  - User profile
  - Quiz performance
  - Best score
  - Learning progress

### 🔹 Pages Included

- Home Page
- Login Page
- Registration Page
- Dashboard
- Quiz Page
- Course Page
- Contact Page
- Feedback Page


## 🛠️ Tech Stack

### Frontend
- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- SCSS

### UI Library
- Material UI (MUI)

### Storage
- Browser Local Storage
